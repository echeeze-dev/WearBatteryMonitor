# Bluetooth 接続状態の表示改善と定期更新ログの修正計画

Bluetoothデバイス（特にカーナビ等）の接続時に、名前が表示されているのに「Disconnected」と表示される矛盾を解消し、定期更新時にもデバイス名が正しく記録されるように改善します。

## 修正内容

### 1. 記録ロジックの修正（Mobile側 `BatteryMonitorService.kt`）
- `startWatchUpdateTimer` 内の定期記録処理を修正します。
- **変更点**: 
    - `currentEarphoneName` が存在する（＝何らかのデバイスが接続されている）場合、バッテリー残量の有無に関わらず、その名前を伴って履歴に記録するようにします。
    - これにより、1分ごとの定期ログにデバイス名が欠落する問題を解消します。

### 2. UI表示の判定ロジック修正（Mobile側 `MainActivity.kt`）
- **メイン画面 (`EarphoneSection`)**:
    - バッテリー残量が不明であっても、デバイス名が存在する場合は「Disconnected」と表示せず、代わりに **「Connected」** または **「—」** を表示するようにします。
- **履歴リスト (`HistoryDetailDialog`)**:
    - 内部数値が `-1`（不明）のデータの表示を以下のように切り分けます。
        - デバイス名がある場合 ➡ 詳細欄に **「Connected」** と表示。
        - デバイス名がない場合 ➡ 詳細欄に **「Disconnected」** と表示。
- **英語表現の整理**:
    - 全体的に `Disconnected` と `Connected` を正しく使い分けるように統一します。

## 検証計画

### 自動テスト
- `gradle_assemble_all` を実行し、ビルドエラーがないことを確認します。

### 手動確認
- バッテリー情報を持たないBTデバイス（カーナビ等）を接続し、メイン画面にその名前と「Connected」が表示されることを確認します。
- 履歴リストを開き、定期更新ログ（⏱ Periodic）にデバイス名が正しく記載されていることを確認します。
- デバイス名がある場合の `-1%` データが「Connected • —」のような形式で表示され、矛盾がないことを確認します。
