# 充電中アイコンのデザイン刷新計画（枠外配置デザイン）

コンプリケーションの視認性を最大化するため、スマホの枠内に収まっていた雷マークを「枠を破って右下に大きく配置する」デザインに変更します。

## 修正内容

### [リソース - Wearアプリ]

#### [MODIFY] [ic_phone_charging.xml](file:///C:/Users/uitti/AndroidStudioProjects/WearBatteryMonitor/wear/src/main/res/drawable/ic_phone_charging.xml)
- **レイアウトの変更**: スマホのアイコンを少し左上に寄せ、空いた右下のスペースに巨大な雷マークを配置します。
- **シルエットの差別化**:
    - 通常時 (`ic_phone_battery`): 垂直な長方形のシルエット。
    - 充電中 (`ic_phone_charging`): 右下が大きく突き出した、非対称で特徴的なシルエット。
- **視認性の確保**: 雷マークがスマホの枠線と重なる部分に「切り欠き（隙間）」を入れるようなデザインにし、重なっても形が崩れないように工夫します。

## 期待される効果
- ウォッチフェイス上の非常に小さな表示（12〜16dp程度）であっても、アイコンの形状が大きく変わるため、充電の有無を一瞬で判別できるようになります。
- 「枠を破る」デザインにより、躍動感のある BattSync らしい外観になります。
