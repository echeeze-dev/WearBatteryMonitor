# グラフのレイアウト改善とラベル視認性向上計画

グラフ内の日付表示をグラフ領域外（上部）に移動し、デバイス名が重ならないよう5段の多段表示に変更します。また、これらを収容するためにグラフの表示高さを拡大します。

## 修正内容

### [UIレイヤー - Mobileアプリ]

#### [MODIFY] [MainActivity.kt (mobile)](file:///C:/Users/uitti/AndroidStudioProjects/WearBatteryMonitor/mobile/src/main/java/com/echeeze/wearbatterymonitor/MainActivity.kt)
- **グラフ高さの拡大**:
    - `BatterySection` および `EarphoneSection` 内のグラフ表示領域（Box）の高度を `80.dp` から **`120.dp`** に拡大します。
- **HistoryGraph の構造刷新**:
    - `Column` を使用して、上部に「日付表示領域」、下部に「メイングラフ領域」を分離して配置します。
- **日付表示の外部化**:
    - 日付ラベル（MM/dd）をグラフの棒が表示されるエリアから追い出し、専用のヘッダー行に描画します。
- **デバイス名の5段表示**:
    - デバイス名が切り替わるたびに、描画位置を **5段階（2dp, 16dp, 30dp, 44dp, 58dp）** でローテーションさせます。
    - これにより、短時間の接続切り替えが発生しても、名前が重ならず階段状に表示されるようになります。

## 期待される効果
- 日付とグラフが重ならないため、いつのデータかが明確になります。
- 多数のデバイスや頻繁な切り替えがあっても、すべてのデバイス名が重ならずに読めるようになります。
- グラフ全体に高さが出るため、バッテリー残量の変化もよりダイナミックに確認できます。

## 検証計画

### 自動テスト
- `gradle_assemble_all` でビルドが通ることを確認します。

### 手動確認
- グラフを表示し、上部に日付、グラフ内に階段状のデバイス名が表示されていることを確認します。
- 横スクロールしても、日付とデバイス名の対応が崩れないことを確認します。
