## 2. 目的と概要

バックグラウンドで動くバッテリー監視処理の構造（常駐サービス方式 vs 定期起動 WorkManager 方式）に関する技術的比較検討内容と、「ワイヤレスイヤホンの接続・切断のリアルタイム検知のために常駐サービス方式を継続採用する」という意思決定理由を、**ADR (Architecture Decision Record / アーキテクチャ決定記録)** として `docs/decisions/` ディレクトリ配下に永続化・管理します。

あわせて、[development_rules.md](file:///C:/Users/uitti/AndroidStudioProjects/WearBatteryMonitor/docs/development_rules.md) に「設計決定時の ADR 作成ルール（`R09`）」を追記します。
