## 2. 目的と動的多段高さ表示アルゴリズムの定義

「デバイス接続開始時（端末名切り替わり時）の 1 回のみ表示」のルールを維持しつつ、デバイス名表示のたびに **「テキストの高さ」と「グラフ描画可能高さ」から利用可能な段数を自動動的計算** し、表示段を切り替えて描画するレスポンシブな多段配置を実現します。

### 自動段数計算＆動的シフティング手法
1. **利用可能段数の自動計算**:
   グラフ表示枠の高さ（`height`）とテキストの測定高さ（`textHeight`）から、利用可能な最大段数（`maxLevels = (height / textHeight).toInt().coerceIn(2, 6)`）を動的に算出します。
2. **接続ごとの表示段（Y 座標）自動切り替え**:
   デバイス接続（端末名表示）のたびに、インデックス（`levelIndex % maxLevels`）により Y 座標描画位置（`levelIndex * textHeight`）を段違いに変更して表示します。
