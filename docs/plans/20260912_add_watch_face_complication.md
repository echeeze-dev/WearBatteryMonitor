# ウォッチフェイス用コンプリケーション（スマホバッテリー）の追加計画

ウォッチフェイス上でスマートフォンのバッテリー状態（残量、充電状態）を確認できる機能（コンプリケーション）を実装します。

## 修正内容

### 1. コンプリケーションサービスの実装 (`MainComplicationService.kt`)
- 現在のダミー実装を、実際のスマートフォンデータ（Data Layer）を読み取るように変更します。
- バッテリー残量を「XX%」という短いテキスト形式（SHORT_TEXT）で提供します。
- スマートフォンが充電中の場合は、テキストや（将来的に）アイコンで表現できるようにします。

### 2. データ更新時の連携強化 (`TileDataUpdateService.kt`)
- スマートフォンから新しいバッテリー情報を受信した際、タイルの更新に加えて、コンプリケーションの更新も即座にリクエストするように拡張します。
- これにより、ウォッチフェイス上の表示が常に最新の状態に保たれます。

### 3. アイコンリソースの追加 (任意/検討)
- 視認性向上のため、スマートフォンを象徴するアイコン（ベクトル画像）を追加し、数値の横に表示されるようにします。

### 4. マニフェストの調整 (`AndroidManifest.xml`)
- コンプリケーションがサポートする型や、アイコンなどの情報を適切に設定します。

## 期待される効果
- アプリやタイルを開くことなく、手首を傾けるだけでスマートフォンのバッテリー残量を確認できるようになります。

## 検証計画

### 自動テスト
- `gradle_assemble_all` を実行し、ビルドエラーがないことを確認します。

### 手動確認
- ウォッチフェイスの設定画面で、新しいコンプリケーション（Phone Battery）を選択できることを確認します。
- 選択後、スマートフォンのバッテリー残量がウォッチフェイス上に表示されることを確認します。
- スマートフォンの残量が変化した際、ウォッチフェイス上の表示も同期して変わることを確認します。
