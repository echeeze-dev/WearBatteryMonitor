# 履歴リストの時刻表示に年月日を追加する計画

## 1. インプット（ユーザー様からのご指示・フィードバック一覧）

本修正計画は、以下のユーザー様からのご指示をインプットとして作成いたしました。

### インプット（ご指摘内容）
- **日時**: 2026年10月10日 17:03頃
- **関連履歴 No**: **`#26`**
- **ご指示原文**:
  > 「リストの時間情報に日付が乗っていません。年月日を表示するようにできませんか？」

本件は、履歴リストの表示形式の改善として対応します。

---

## 2. 目的と原因分析

履歴一覧で各イベントの時刻を表示する際、`yyyy/MM/dd HH:mm:ss` のフォーマットを用意している一方で、表示時に `substringAfter(" ")` を使って時刻部分だけを切り出しているため、年月日が見えていません。

### 原因分析
1. **表示文字列の整形が不適切**:
   `HistoryDetailDialog.kt` で日付と時刻を `yyyy/MM/dd HH:mm:ss` 形式で生成した後、`substringAfter(" ")` により日付を削除してしまっているため、一覧の時間欄から日は見えません。
2. **UI 上の意図が不明瞭**:
   画面内で "時間情報" として表示されているが、日付情報が省略されており、イベントの発生日を識別しづらい状態です。

## 4. 実装ステップ

### ステップ 1: タスク対応履歴 (`task_history.md`) への事前新規登録
- ルール `[R11]` に従い、本タスクを新しい履歴 No として `docs/task_history.md` に `[PENDING]` 状態で追加します。

### ステップ 2: 履歴一覧の表示フォーマット修正
- `HistoryDetailDialog.kt` の `sdf.format(Date(entry.timestamp)).substringAfter(" ")` を見直し、日付と時刻を含む表示形式へ置き換えます。
- 例: `2026/10/10 17:03:12` のように、年月日と時刻を両方表示する方針で対応します。

### ステップ 3: 表示レイアウトの確認
- 日付付き表示が狭い列幅でも見切れないかを確認し、必要に応じて `width` や文字サイズの調整を行います。
- 表示の多さを増やした場合も、理由ラベル、残量、詳細のレイアウトが崩れないことを確認します。

### ステップ 4: 変更後の静的確認
- `analyze_file` または該当コードのレビューで、表示ロジックの破綻がないことを確認します。
- テスト自動実行は行わず、ビルド確認が必要になった場合のみ最小限の検証に留めます。
