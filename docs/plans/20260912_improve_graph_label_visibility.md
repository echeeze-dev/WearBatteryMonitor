# グラフ内のラベル視認性向上と重なり防止計画

グラフ内のデバイス名、日付、時刻ラベルをより大きく、太くして見やすくするとともに、デバイス名が重ならないように表示位置を調整します。

## 修正内容

### [UIレイヤー - Mobileアプリ]

#### [MODIFY] [MainActivity.kt (mobile)](file:///C:/Users/uitti/AndroidStudioProjects/WearBatteryMonitor/mobile/src/main/java/com/echeeze/wearbatterymonitor/MainActivity.kt)
- **ラベルのスタイル調整**:
    - **デバイス名**: フォントサイズを `8.sp` から **`10.sp`** に拡大し、**太字 (Bold)** に変更します。また、色を少し濃くして視認性を高めます。
    - **日付ラベル**: フォントサイズを `9.sp` から **`10.sp`** に拡大します。
    - **時刻ラベル**: フォントサイズを `7.sp` から **`9.sp`** に拡大します。
- **デバイス名の重なり防止ロジック**:
    - デバイス名の描画時に、直前に描画したラベルの右端座標を保持します。
    - 新しいラベルが前のラベルと重なる（または近すぎる）場合は、描画位置を上下にずらす（2段表示にする）ことで、すべての名前が読めるようにします。
- **日付ラベルの重なり防止**:
    - 同様に、日付ラベルも他のラベルと重ならないよう、表示位置を最適化します。

## 期待される効果
- 小さな画面でも、どのデバイスのデータか、いつのデータかが一目で判別できるようになります。
- デバイスが頻繁に切り替わる場合でも、名前が重なって読めなくなることがなくなります。

## 検証計画

### 自動テスト
- `gradle_assemble_all` を実行し、ビルドエラーがないことを確認します。

### 手動確認
- グラフを表示し、デバイス名や日付が以前よりもはっきりと見えることを確認します。
- デバイスが短期間で切り替わった箇所で、名前が上下に分かれて表示され、重なっていないことを確認します。
