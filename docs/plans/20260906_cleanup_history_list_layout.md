# 履歴リストのレイアウト整理と表記の適正化計画

履歴詳細ダイアログのリスト表示において、各項目の表示位置を固定して視認性を向上させるとともに、切断時の冗長な表記を整理し、英語表現をより自然なものに統一します。

## 修正内容

### 1. レイアウトの構造化（スマホ側 `MainActivity.kt`）
- `HistoryDetailDialog` 内のリスト各行を3列構成に固定します。
    - **左列 (約80dp)**: 時刻を表示。
    - **中央列 (可変)**: 2段構成。
        - 上段（太字）: 記録理由（例：`⏱ Periodic (1m)`）。
        - 下段（小文字）: デバイス名および充電状態（例：`Pixel 8 • Charging`）。
    - **右列 (約60dp)**: バッテリー残量を右寄せで表示。
- これにより、理由の長さに関わらず残量や時刻の位置が垂直に揃い、表のような整然とした見た目になります。

### 2. 表記の適正化と冗長性の排除
- **英語表現の統一**: `disconnect` を、より一般的な状態表現である **`Disconnected`** に統一します。
- **切断時（-1%）の特別扱い**:
    - バッテリー残量表示（右列）を `%` 表記ではなく **`—`** (ダッシュ) に変更します。
    - 中央列のステータスに `Disconnected` と表示することで、「何が起きたか」を明確にしつつ数値の重複を防ぎます。

### 3. 情報の優先順位付け
- 情報が存在しない（マイグレーション前のデータなど）場合でも、レイアウトが崩れないように空の領域を確保します。
- デバイス名と充電状態を `•` で繋ぐことで、情報の区切りを明確にします。

## 検証計画

### 自動テスト
- `gradle_assemble_all` を実行し、ビルドエラーがないことを確認します。

### 手動確認
- 履歴リストを開き、各列が垂直にきれいに揃っていることを確認します。
- 切断時のデータ（-1%）が、理由欄に `Disconnected`、数値欄に `—` と表示されていることを確認します。
- 以前の `disconnect` 表記がすべて `Disconnected` に変わっていることを確認します。
