# Roomデータベースによるデータ永続化の実装計画

アプリのプロセス終了やアップデート時にバッテリー履歴データが消えてしまう問題を解決するため、Roomデータベースを導入してデータを永続化します。

## 変更内容

### 1. 依存関係の追加
- `libs.versions.toml` に Room のバージョンとライブラリを追加します。
- `mobile/build.gradle.kts` に Room の依存関係と KSP プラグインを追加します。

### 2. データレイヤーの実装
- `BatteryEntry` を Room の Entity として定義します。
- `BatteryDao` を作成し、データの挿入、取得、古いデータの削除（1200件制限の維持）を行うメソッドを定義します。
- `AppDatabase` クラスを作成します。

### 3. サービスレイヤーの修正 (`BatteryMonitorService.kt`)
- 起動時にデータベースから過去のデータを読み込むようにします。
- 新しいデータが追加されるたびにデータベースに保存します。
- メモリ上のリストとデータベースの同期を維持します。

### 4. メイン画面の修正 (`MainActivity.kt`)
- サービスから取得するデータがデータベース由来になるため、表示の一貫性が保たれます。

## 検証計画

### 自動テスト
- `gradle_assemble_all` を実行し、ビルドエラーがないことを確認します。

### 手動確認
- アプリを起動し、しばらくデータを蓄積させます。
- アプリをタスクマネージャーから強制終了、または端末を再起動します。
- 再度アプリを開き、過去のグラフデータが正しく復元されていることを確認します。
- 履歴リストに過去のデータが残っていることを確認します。
