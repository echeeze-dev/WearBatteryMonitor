# 充電中アイコンの視認性向上計画

コンプリケーション上の「充電中」状態をより明確に判別できるようにするため、アイコン内の雷マークを大型化し、デザインを調整します。

## 修正内容

### [リソース - Wearアプリ]

#### [MODIFY] [ic_phone_charging.xml](file:///C:/Users/uitti/AndroidStudioProjects/WearBatteryMonitor/wear/src/main/res/drawable/ic_phone_charging.xml)
- **雷マークの大型化**: アイコン中央の雷マークを、スマートフォンの画面領域いっぱいに広がるように大きく描画し直します。
- **デザインの強調**: 単に大きくするだけでなく、線の太さや角度を調整して、小さなコンプリケーション枠内でも「雷」の形状がはっきりと認識できるようにします。
- **アウトラインの調整**: スマホの枠線と雷マークが重なって形が崩れないよう、適切な余白（マージン）を確保します。

## 期待される効果
- ウォッチフェイスの小さな表示枠（Complication）であっても、一目で「今はスマホを充電している」ことが分かるようになります。
- 通常時と充電時のアイコンのシルエットの差が大きくなり、誤認を防げます。

## 検証計画

### 自動テスト
- `gradle_assemble_all` を実行し、ビルドエラーがないことを確認します。

### 手動確認
- 実際に Wear OS デバイス（またはエミュレータ）でコンプリケーションを確認し、充電中のアイコンが十分に目立っていることを確認します。
