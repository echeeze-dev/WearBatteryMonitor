# 充電中アイコンのデザイン修正（右上配置デザイン）

ユーザーの提案に基づき、充電を示す雷マークをスマホの「右上」を突き抜けるように配置し、より直感的な視認性を実現します。

## 修正内容

### [リソース - Wearアプリ]

#### [MODIFY] [ic_phone_charging.xml](file:///C:/Users/uitti/AndroidStudioProjects/WearBatteryMonitor/wear/src/main/res/drawable/ic_phone_charging.xml)
- **配置の変更**: 雷マークを右下から右上に移動します。
- **デザイン調整**: 
    - スマホのアイコンを中央やや左下に配置し、右上のスペースを確保します。
    - 雷マークが右上の角を大胆に横切るように配置し、シルエットそのものを「右上が鋭い形」に変形させます。
- **視認性の向上**: スマホのバッテリーステータス（通知エリア等）の標準的な位置に近い右上に配置することで、心理的にも「バッテリーの状態」であることを認識しやすくします。

## 期待される効果
- ウォッチフェイスの小さな枠内でも、右上の形状変化が際立ち、充電中であることが即座に伝わります。
- バッテリー情報の標準的な配置（右上）に合わせることで、直感的なユーザー体験を提供します。
