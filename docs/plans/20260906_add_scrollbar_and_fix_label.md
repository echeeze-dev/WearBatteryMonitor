# 履歴リストのスクロールバー追加と更新間隔ラベルの修正計画

履歴リストの項目数が多いため、スクロール位置を把握しやすくするためのスクロールバーを追加します。また、更新間隔設定のラベル表示の不備を修正します。

## 修正内容

### 1. 履歴リストへのスクロールバー追加（スマホ側 `MainActivity.kt`）
- `HistoryDetailDialog` 内の `LazyColumn` に、垂直方向のスクロールバーを表示する機能を追加します。
- Compose の標準機能ではスクロールバーが自動表示されないため、`LazyListState` を使用してスクロール位置に応じたインジケータを描画するカスタム実装を導入します。
- これにより、1200件の膨大なデータの中でも現在位置が直感的に分かるようになります。

### 2. 更新間隔セレクターのラベル修正（スマホ側 `MainActivity.kt`）
- `UpdateIntervalSelector` の右端のラベルが、ロジック上の最大値（1h）と一致せず「10m」のままになっていたのを修正します。
- 実際の最大値に合わせて「1h」と表示するように変更し、ユーザーの混乱を防ぎます。

## 検証計画

### 自動テスト
- `gradle_assemble_all` を実行し、ビルドエラーがないことを確認します。

### 手動確認
- 履歴リストを開き、スクロール時に右側にスクロールバーが表示されることを確認します。
- メイン画面の「Update Interval」スライダーの右端の文字が「1h」になっていることを確認します。
