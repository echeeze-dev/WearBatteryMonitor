# プライバシーポリシー (Privacy Policy)

**BattSync**（以下「本アプリ」）は、ユーザーのプライバシーを尊重し、ユーザーの個人情報の保護に細心の注意を払っております。本プライバシーポリシーでは、本アプリにおけるデータの収集、利用、および管理方法について説明いたします。

---

## 1. 収集および利用する情報

本アプリは、マルチデバイス間でのバッテリー統合監視およびグラフ表示機能を提供するため、以下の情報を取得・利用します。

- **バッテリー情報**: スマートフォンおよびスマートウォッチのバッテリー残量（%）、充電状態、およびタイムスタンプ
- **接続デバイス情報**: ペアリングされた Bluetooth イヤホン等のデバイス名およびバッテリーレベル
- **端末情報**: 端末のモデル名（例: スマートフォンの機種名）

---

## 2. データの利用目的

取得した情報は、以下の目的のみに使用されます。

- アプリ画面上でのバッテリー残量、接続状態、および履歴グラフの表示
- Google Wearable Data Layer API を通じた、ペアリングされたスマートウォッチおよびスマートフォン間でのバッテリー情報の自動同期
- Wear OS タイル画面および Watch Face コンプリケーションへのバッテリー情報の給送

---

## 3. データの保管および第三者提供

- **データの保管**: 収集されたバッテリー履歴データは、ユーザーの端末ローカルデータベース（Room Database）内にのみ永続化されます。
- **外部送信および第三者提供**: 本アプリが収集したデータは、外部の第三者サーバーや追跡（トラッキング）サービスへ送信・提供されることは一切ありません。データ同期は、ユーザーが所有するペアリング端末間（Google Play Services 経由）でのみ安全に行われます。

---

## 4. 必要な権限 (Permissions)

本アプリの機能を提供するために、以下の権限を使用します。

- `BLUETOOTH_CONNECT`: 接続されている Bluetooth イヤホン等のデバイス名およびバッテリーレベルを取得するために使用します。
- `POST_NOTIFICATIONS` / `FOREGROUND_SERVICE`: バックグラウンドでバッテリー変化を監視し、常駐通知を表示するために使用します。
