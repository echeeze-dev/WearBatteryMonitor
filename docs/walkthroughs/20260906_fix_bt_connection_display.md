# Bluetooth 接続状態の表示改善と定期更新ログの修正 - 完了報告

Bluetoothデバイス（特にカーナビ等）の接続時に、名前があるのに「Disconnected」と表示される問題を修正し、定期更新ログの正確性を向上させました。

## 実施した変更

### 1. 定期更新ロジックの改善 (`BatteryMonitorService.kt`)
- `startWatchUpdateTimer` 内の定期記録処理を修正しました。
- **変更内容**: `currentEarphoneName` が存在する場合、バッテリー残量の有無に関わらず、そのデバイス名を伴って履歴を記録するようにしました。
- **効果**: 1分ごとの定期ログにおいて、接続中のデバイス名が欠落することなく記録されるようになりました。

### 2. UI表示判定の適正化 (`MainActivity.kt`)
- **メイン画面**: 
    - 接続状態の判定を「バッテリーの有無」から **「デバイス名（名前）の有無」** に変更しました。
    - 名前がある場合は、バッテリー不明でも「Connected」と表示し、矛盾を解消しました。
- **履歴リスト**:
    - バッテリー残量が `-1`（不明）のデータにおいて、名前があれば詳細欄に「Connected」、なければ「Disconnected」と表示するようにしました。
    - 充電中フラグやデバイス名の表示ロジックを整理し、より正確な状態が反映されるようにしました。

## 検証結果

### ビルド
- `gradle_assemble_all`: **成功**

### 改善効果
- カーナビ接続時など、バッテリー情報が取れない場合でも、画面上にデバイス名と「Connected」が正しく表示されます。
- 履歴リストの「⏱ Periodic」項目に、接続中のデバイス名が常に併記されるようになりました。
- 切断時のみ「Disconnected」と表示されるようになり、情報の正確性が向上しました。
